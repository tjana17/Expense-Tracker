# 📊 Expense Tracker — iOS (SwiftUI + Firebase)

 <p align="center">
  <img src="https://github.com/tjana17/Expense-Tracker/blob/main/screens/expense_tracker_banner.png" alt="Expense Tracker Banner" width="100%" />
</p> 

A clean, modern, and intuitive **Expense Tracker App** built using **SwiftUI**, powered by **Firebase Authentication**, **Firestore Database**, and **Firebase Storage**.

Track daily spending, visualize financial habits, and securely sync data across devices — beautifully and effortlessly.

---

## 🌟 Features

### 🔐 User Authentication
- Email & password login  
- Firebase Auth secure authentication  
- User profile synced with Firebase  
- Password reset support  

### 💸 Expense Management
- Add, edit, delete expenses  
- Categorize by type (Food, Travel, Bills, etc.)  
- Add notes and date  
- Smooth SwiftUI interface  

### 📈 Statistics & Insights
- Daily & monthly summaries  
- Category-wise breakdown  
- SwiftUI charts and analytics  

### ☁️ Cloud Sync with Firebase
- Real-time Firestore syncing  
- Device-to-device syncing  
- User-specific data isolation  

### 🎨 Beautiful UI
- Pure SwiftUI  
- Dark mode & animations  
- Clean, modern layout

## 🚀 Getting Started

### 1️⃣ Clone Repository
```bash
git clone https://github.com/tjana17/Expense-Tracker.git

```
### 2️⃣ Open in Xcode
Requires Xcode 15+.
### 3️⃣ Add Firebase
Create a Firebase project<br/>
Enable: Auth, Firestore, Storage<br/>
Download GoogleService-Info.plist<br/>
Add it to the Xcode project
### 4️⃣ Install Swift Packages
FirebaseAuth<br/>
FirebaseFirestore<br/>
FirebaseStorage<br/>
### 5️⃣ Run the app
Cmd + R
